# What is this project?

> *AI-reviewed content: may change at any time and should not be fully trusted. See the [disclaimer](disclaimer.md).*

Dino Cap 1 (made by Triniti Interactive, like Dino Cap 2 and 3) is a side-scrolling dinosaur shooter that was released for iOS. This project rebuilds it for Windows PC and
Android in the Unity engine, aiming to behave exactly like the original iPad version unless a difference is clearly
labelled.

**You can:** download and play it ([Download guide](download-guide.md), [PC controls](controls-pc.md)); read how the
original works ([How it works](../how-it-works/01-overview.md)); or follow how each rule was proven and later
corrected ([task index](../history/task-index.md), [corrected claims](../history/corrected-claims.md),
[timeline](../history/timeline-and-agents.md), [fidelity and divergences](../fidelity/shipped-quirks-and-divergences.md)).

**Modes:** City Grind (street levels, shop, weapon upgrades) and Jungle Blitz (survival).

**What this is not:** a remake with new gameplay. Balance, timing and even odd original quirks are kept on purpose.
Some presentation options (Internal 2X, widescreen) are modern extras and are always labelled as such.
