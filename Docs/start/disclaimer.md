# Disclaimer: please read

**Dino Cap 1, 2 and 3 were made by Triniti Interactive.** That fact, and other plainly obvious facts such as the names of
the games and their developer, are the only statements in this documentation that do not depend on analysis.

**Everything else in this documentation was produced with, and reviewed by, AI tools** (AI coding agents did the
analysis, drafting and cross-checking of one another's work, and a human owner tested on real devices and made the
decisions). It is therefore:

- **subject to change at any time** as new evidence is found or mistakes are corrected;
- **not guaranteed to be 100% accurate or complete**, and it should not be fully trusted. Confidence labels
  (PROVEN, LIKELY, POSSIBLE, UNRESOLVED, FALSIFIED) say how well a statement is supported, and even PROVEN applies only to
  the exact claim stated;
- written about a reconstruction that has known open items (see [fidelity and divergences](../fidelity/shipped-quirks-and-divergences.md)),
  including things that were first accepted and later found wrong ([corrected claims](../history/corrected-claims.md)).

If a page here disagrees with what you see in the original game, the original game is right. Please report differences.
